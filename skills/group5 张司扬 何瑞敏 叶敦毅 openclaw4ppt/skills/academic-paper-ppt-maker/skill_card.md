# Skill Card: Academic Paper PPT Maker

## 1. Skill 基本信息

| 项目 | 内容 |
|---|---|
| Skill 名称 | academic-paper-ppt-maker |
| 中文名称 | 中文学术论文汇报 PPT 生成 skill |
| 所属科研场景 | 组会汇报、课程论文展示、论文精读分享 |
| 主入口文件 | `SKILL.md` |
| 上游依赖 | `paper-pdf-assets-pdftoppm` 生成的原论文图表素材 |
| 上游输入文件 | `asset_manifest.md`、`crop_qc.md`、`paper_assets/*.png` |
| 下游输出 | 10-20 页中文 PPTX |

## 2. 一句话简介

`academic-paper-ppt-maker` 用于根据论文 PDF、论文分析笔记或已裁剪图表素材生成可直接汇报的中文学术 PPT，强调原论文图表、关键公式、实验数据、中文讲解、微软雅黑字体、来源标注和排版质检。

## 3. 解决的科研问题

论文 PPT 制作不是简单把摘要贴进幻灯片。真实组会汇报需要：

- 清楚说明研究背景、问题定义、论文动机和核心贡献。
- 用原论文方法图讲清楚方法框架。
- 用公式页解释关键机制或损失函数。
- 用主实验表和消融实验表说明性能和模块有效性。
- 用可视化结果展示方法效果。
- 每页都能讲，而不是只堆图。
- 保证中文、字体、图表来源、图片比例和元素位置都可靠。

本 skill 将论文讲解 PPT 的内容结构和视觉质量要求写成固定规范，避免生成“只有图没有讲解”或“文字重叠、公式变形”的低质量 PPT。

## 4. 输入与输出

### 输入

| 输入 | 示例 | 说明 |
|---|---|---|
| 论文分析 | 动机、贡献、方法、实验、局限 | 可由模型阅读论文生成 |
| 原论文图表素材 | `paper_assets/fig*.png`、`table*.png` | 推荐必备 |
| 素材清单 | `asset_manifest.md` | 说明图表来源和尺寸 |
| 裁剪 QC | `crop_qc.md` | 用于判断能否进入 PPT 阶段 |
| 用户要求 | 15 分钟、10-20 页、中文 | 决定页数和风格 |

### 输出

| 输出 | 说明 |
|---|---|
| 逐页大纲 | 页码、标题、本页目的、核心内容、素材、版式建议、讲稿提示 |
| 公式 PNG | 至少一个关键公式，LaTeX 渲染为透明 PNG |
| PPTX | 中文、微软雅黑、含来源标注、适合组会汇报 |
| 最终质检结果 | 图片比例、文字重叠、页数、来源、公式、文件大小等 |

## 5. 推荐 PPT 结构

默认适合 15 分钟汇报，生成 12-16 页：

1. 封面
2. 研究背景
3. 问题定义与挑战
4. 相关工作与不足
5. 论文动机与贡献
6. 方法整体框架
7. 核心模块一
8. 核心模块二或训练策略
9. 损失函数或关键公式
10. 数据集与实验设置
11. 主实验结果
12. 消融实验
13. 可视化结果
14. 优点、局限与讨论
15. 总结与 Q&A

## 6. 强制内容规范

| 规范 | 要求 |
|---|---|
| 语言 | PPT 内容必须中文讲解，关键术语可保留英文 |
| 字体 | 全文使用 Microsoft YaHei / 微软雅黑 |
| 图表 | 优先使用原论文 Figure/Table |
| 来源 | 每个原论文图表必须标注来源 |
| 公式 | 每篇论文 PPT 至少包含一个关键公式 |
| 公式格式 | 公式必须由 LaTeX 渲染为透明 PNG |
| 图片比例 | 必须保持原图长宽比 |
| 讲解文字 | 内容页不能只有图，必须有实质讲解 |
| 质检 | 保存前检查重叠、路径、页数、文件大小 |

## 7. 与普通 PPT 生成的区别

| 对比项 | 普通生成 | 本 Skill |
|---|---|---|
| 内容 | 可能只总结摘要 | 覆盖背景、方法、公式、实验、消融、讨论 |
| 图表 | 可能用重绘或无关图片 | 优先使用原论文裁剪图表 |
| 公式 | 可能用普通文本模拟 | 必须 LaTeX 渲染为透明 PNG |
| 语言 | 中英混杂不稳定 | 中文讲解，关键术语保留英文 |
| 字体 | 可能不统一 | 微软雅黑 |
| 排版检查 | 可能缺少检查 | 强制检查比例、重叠、来源和讲解文字 |

## 8. 质量检查

生成 PPT 前：

- `asset_manifest.md` 必须存在。
- `crop_qc.md` 必须存在。
- 关键图表不能截断或混入正文。
- 方法图、主实验表、消融表、可视化结果应尽量齐全；若论文没有，应明确说明。

生成 PPT 后：

- 检查页数是否在 10-20 页。
- 检查所有内容页是否有中文讲解。
- 检查是否至少包含一个关键公式 PNG。
- 检查所有图表是否保持比例。
- 检查是否存在真实重叠。
- 检查图表是否有来源标注。
- 检查文件大小是否合理。

## 9. Demo

### Dark-ISP

基于原论文方法图、主实验表、消融表和可视化结果，生成中文组会 PPT。迭代中修复了图片比例、文字重叠、公式 PNG 缩放和页面留白问题。

### PromptIR

基于 PromptIR 的方法图、架构图、实验表和可视化结果生成 PPT。初版缺少讲解和公式，后续按 skill 要求加入中文讲解、微软雅黑和关键公式，形成 `PromptIR_v5.pptx`。

## 10. 局限性

- 如果上游图表裁剪质量差，本 skill 不应强行生成 PPT，应返回重裁。
- 论文理解仍可能需要人工复查，尤其是公式含义和实验结论。
- 对特别长的综述论文或没有图表的理论论文，需要调整默认结构。
- 自动重叠检查可能存在假阳性或漏检，最终仍建议打开 PPT 抽查。
